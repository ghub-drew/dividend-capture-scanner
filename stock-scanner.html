Dividend Capture Scanner

Automated workflow — S&P 500 · Yahoo Finance · IBKR (coming soon)

1
Fetch S&P 500 Universe
Data Ingestion
Pulls the current list of 503 S&P 500 tickers from Wikipedia at run time, so the universe always reflects the latest index composition — no manual updates needed.
Wikipedia / pandas 503 tickers Auto-refresh daily
2
Pull Stock Data via Yahoo Finance
Per-ticker enrichment
For each ticker, fetches live fundamentals using yfinance: ex-dividend date, dividend rate, current price, average daily volume, beta, and sector. Data is pulled in parallel to keep runtime manageable.
yfinance Ex-dividend date Price · Volume · Beta Sector
3
Apply Capture Filters
Candidate screening
Each stock is tested against five filters simultaneously. Any failure disqualifies the stock. All thresholds are configurable at the top of the script.
Ex-date window
Next 14 days
Min yield / payment
≥ 0.5%
Min avg daily volume
≥ 500,000 shares
Stock price range
$10 – $500
⚖️
Does the stock pass all filters?
All five criteria must be met to advance to scoring
No — Skip
Stock discarded,
move to next ticker
Yes — Score it
4
Score & Rank Candidates
Prioritisation
Each passing stock receives a composite score. Higher yield and more days until ex-date push the score up; higher beta (price volatility) pulls it down. The shortlist is sorted best-first.
Yield ×1000 (reward) Days remaining ×0.5 (reward) Beta ×2 (penalty)
5
Output Morning Shortlist
Review & Export
Ranked table printed to the terminal and saved as a dated CSV (candidates_YYYYMMDD.csv) for record keeping.

How to Run the Scanner

Run this each morning to get a fresh shortlist of candidates.

1
One-time setup
Install the required Python packages. Only needed once.
pip install yfinance pandas requests lxml
2
Navigate to the project folder
Open a terminal (PowerShell or Command Prompt) and go to the scanner directory.
cd "C:\Users\andre\Documents\stock scanner"
3
Run the scanner
This scans all 503 S&P 500 stocks and takes 3–5 minutes to complete.
python dividend_scanner.py
4
Review the output
The ranked shortlist prints in the terminal and is also saved as a dated CSV file in the same folder.
candidates_YYYYMMDD.csv
Tip: All filter thresholds (minimum yield, price range, volume, ex-date window) are set at the top of dividend_scanner.py and can be adjusted at any time.
